# TikTok → Telegram репостер

Бесплатный бот, который постит новые видео с TikTok-аккаунтов в твой Telegram-канал.
Крутится на GitHub Actions по расписанию — свой сервер не нужен.

## Структура

```
.
├── bot.py                       # сам скрипт
├── requirements.txt             # зависимости
├── state.json                   # создастся сам после первого запуска
└── .github/workflows/repost.yml # расписание запуска
```

## Настройка (по шагам)

### 1. Создай бота
Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получишь **токен**
(строка вида `123456:ABC-...`).

### 2. Подготовь канал
- Создай Telegram-канал (или возьми существующий).
- Добавь своего бота в **администраторы** канала (иначе он не сможет постить).
- ID канала: для публичного проще всего использовать `@имя_канала`.
  Для приватного нужен числовой ID вида `-100xxxxxxxxxx`.

### 3. Создай репозиторий на GitHub
Залей туда эти файлы.
- **Публичный** реп — минуты Actions безлимитны, но код виден всем
  (токен всё равно в секретах, не в коде — так что ок).
- **Приватный** — 2000 бесплатных минут/мес, для проверки раз в 30 мин хватает с запасом.

### 4. Добавь секреты
`Settings` → `Secrets and variables` → `Actions` → `New repository secret`.
Создай три штуки:

| Имя | Значение |
|-----|----------|
| `BOT_TOKEN` | токен из шага 1 |
| `CHANNEL_ID` | `@имя_канала` или `-100...` |
| `TIKTOK_USERS` | ники через запятую, напр. `charlidamelio, zachking` |

### 5. Включи запись для Actions  ← важно, легко пропустить
`Settings` → `Actions` → `General` → раздел **Workflow permissions** →
выбери **Read and write permissions** → Save.
Без этого бот не сможет сохранять `state.json`, и будет постить дубли.

### 6. Первый запуск
Вкладка `Actions` → выбери workflow **TikTok to Telegram** → **Run workflow**.
Первый прогон ничего не постит — он просто запоминает текущие видео как
«уже отправленные». Дальше по расписанию будут прилетать только **новые**.

## Настройки

- **Частота:** строка `cron` в `repost.yml`. `*/30 * * * *` = каждые 30 мин.
  Время в UTC, без таймзон.
- **Сколько видео за раз:** переменная `MAX_PER_RUN` (по умолчанию 5) — защита
  от флуда, если вдруг появилось много новых сразу.

## Если что-то не так

- **Список видео пустой / в логах «TikTok ограничил IP».**
  TikTok иногда режет запросы с дата-центровых IP GitHub. Тогда нужны либо
  cookies (экспортировать `cookies.txt` из браузера, добавить в реп/секрет и
  передать в `yt_dlp` через опцию `cookiefile`), либо прокси.
- **Видео не постятся, в логах «Telegram отклонил».**
  Проверь, что бот — админ канала и `CHANNEL_ID` указан верно.
- **Постятся дубли.** Не включена запись для Actions (шаг 5) — `state.json`
  не сохраняется между запусками.
- **Большие видео (>50 МБ)** бот не может залить как файл и шлёт ссылкой —
  это ограничение Bot API, а не скрипта.

## Про легалку
Репост чужого контента нарушает правила TikTok и попадает под копирайт —
канал могут дропнуть по жалобе. Для своих аккаунтов вопросов нет.
